Approval Flow Builder

Multi-level Purchase Order approvals with a drag-and-drop visual builder

Odoo 19 Free & open source (LGPL-3) 23 automated tests

Design your approval chain visually

Add approvers, drag to reorder, and set amount rules — for example, Finance only above ₹2,00,000 and the Director only above ₹10,00,000. No forms full of rules: you see the chain exactly as it runs.

Key features

Visual builder

Drag-and-drop approval chains. Approvers can be a specific employee or a user group (any member can approve).

Amount rules

Each step can apply only above an amount. Orders below a configurable minimum are confirmed directly — no approval needed.

No bypassing

Confirm Order is blocked until approved. The order is locked while waiting, and a confirmed order cannot be increased above the approved amount.

My Approvals

Approvers get a to-do and an inbox notification, and approve or reject from a kanban board in one click.

Reject with a reason

A reason is required. The requester is notified, edits the order and submits again — or withdraws the request.

Audit log

Every Submitted, Approved, Rejected and Withdrawn event with user, step, time and reason. Entries cannot be edited.

Self-approval control

Optionally prevent people from approving their own orders; the step goes to an Approval Flow Administrator instead.

Secure by design

Two security groups and record rules: users only see requests they submitted, decided or must decide.

Tested

23 automated tests; Odoo's own Purchase test suite passes with the module installed.

Approvers act in one click

Each approver sees only what is waiting for them.

The order is locked while it waits

Lines, vendor and currency cannot change during approval, and Confirm Order stays hidden.

Reject with a reason

Full history and audit log

Small orders don't wait

Below your minimum amount, the order shows "No approval needed" and can be confirmed directly.

Simple configuration

Getting started

  1. Install the module (depends on Purchase, Employees and Discuss).
  2. Give approvers the Approval Flow → Approver role and flow designers the Administrator role. Link each approving employee to a user.
  3. Open Approval Flow Builder → Approval Flows → New → Open Visual Builder and build your chain.
  4. In Configuration → Settings, turn on Require approval, set the minimum amount and the default flow.
  5. Create a Purchase Order above the minimum and click Submit for Approval.

Full user guide, source code and issue tracker: github.com/6oshan/approval_flow_builder
